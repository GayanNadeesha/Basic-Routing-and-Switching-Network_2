# Basic Routing and Switching Network_2

## 📌 Project Overview
This project is a Cisco Packet Tracer simulation that demonstrates basic routing and switching concepts. It is designed for CCNA beginners to understand network topology creation, IP addressing, and device configuration.

## 🎯 Features
- Central router connecting multiple LANs  
- Switch-based access networks  
- IPv4 addressing scheme  
- End-to-end connectivity testing  
- Dedicated server (192.168.1.100)  

## 🛠️ Tools Used
- Cisco Packet Tracer  
- CLI configuration  

## 🚀 How to Run
1. Open Cisco Packet Tracer  
2. Click **File → Open**  
3. Select the `.pkt` file  
4. Use ping to test connectivity  
5. Access the server using its IP address  

## 📚 Learning Outcomes
- Understanding of basic network topology  
- Router and switch configuration skills  
- Inter-network communication  
- Server integration in LAN
